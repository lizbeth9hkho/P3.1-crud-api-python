# CRUD API en Python

## Descripción

Este proyecto consiste en un script desarrollado en Python que realiza operaciones CRUD sobre una API REST utilizando la librería `requests`.

CRUD significa:

* **Create:** Crear un registro mediante POST.
* **Read:** Consultar registros mediante GET.
* **Update:** Actualizar un registro mediante PUT.
* **Delete:** Eliminar un registro mediante DELETE.

## Requisitos

* Python 3
* Librería `requests`

## Instalación

Instalar la librería `requests` con el siguiente comando:

```bash
pip install requests
```

## Ejecución

Para ejecutar el programa:

```bash
python crud_api.py
```

## Operaciones realizadas

El script realiza las siguientes operaciones sobre la API:

1. **GET** – Consulta publicaciones.
2. **POST** – Crea una nueva publicación.
3. **PUT** – Actualiza una publicación existente.
4. **DELETE** – Elimina una publicación.

## API utilizada

Se utiliza la API de prueba JSONPlaceholder.
